Runs on your machine, not ours

Polyergon is a local app around the CLIs you already use. Your code, keys and transcripts stay on your computer.

Local only

Listens on 127.0.0.1 and rejects requests from other websites.

Keys stay put

API keys live in a file only your user can read. The browser never sees them.

You stay in charge

Sessions ask before running commands, unless you turn that off.

MIT licensed

Free and open source. Read it, fork it, change it.

Install in a minute

macOS today. Linux should work for sessions.

  • Mac installer: nothing else needed. It sets up Node for you, no admin password.
  • With npx: Node.js 20 or newer
  • Claude Code or GitHub Copilot CLI, logged in
  • gh for PRs and Ship it (optional)
Download for Mac
  1. Unzip and double-click Polyergon Installer.
  2. The first time, macOS says it can't verify the app. Open System Settings → Privacy & Security, scroll down, click Open Anyway, then open the installer again.
  3. Click Install. Polyergon opens when it's ready, and starts when you log in.

Or in Terminal, same installer, no warning:

$ curl -fsSL https://polyergon.ai/install.sh | bash

Or with npx, if you have Node:

$ npx polyergon # opens Polyergon in its own window

Then install it as an app: Settings → App → Install Polyergon. You get a Dock icon, and notifications come from Polyergon.
